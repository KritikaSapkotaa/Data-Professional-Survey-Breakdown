# Data Professional Survey Breakdown

Power BI dashboard analyzing survey data from 630 data professionals covering job roles, salaries, satisfaction, career paths, and demographics.

## Dataset
- 630 responses, 28 columns
- Fields: role, salary, industry, programming language, satisfaction ratings, 
  career-switch status, demographics (age, gender, country, education)

## Tools
- Power BI Desktop
- Excel
- DAX

## Key Questions Explored
- What roles/salaries are most common?
- How satisfied are data professionals with their jobs?
- How hard is it to break into a data career?
- What programming languages are most popular?

## How to Use
1. Clone the repo
2. Open the `.pbix` file in Power BI Desktop
3. Refresh data source if needed
